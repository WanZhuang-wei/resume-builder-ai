数据流

① 用户按 Ctrl+Shift+S → 截图选框出现
② 框选招聘网站上的岗位信息 → Python 截取该区域
③ OCR (Tesseract) 提取文字 → AI 解析为结构化数据
④ 写入本地 SQLite → 通过 REST API 通知前端
⑤ 前端更新知识库面板 → 用户开始分析匹配度
