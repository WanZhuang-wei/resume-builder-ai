# Resume Builder AI - 简历生成助手

> AI驱动的智能简历生成与求职辅助工具 | 纯前端PWA应用 | 数据本地存储，隐私安全

## 项目概述

面向求职者的AI驱动型简历管理工具，集成了**文档智能提取、AI简历生成、岗位匹配分析、求职问答咨询**四大核心能力。采用纯前端架构，所有数据存储于浏览器本地 IndexedDB，无需后端服务器，开箱即用。

支持上传 PDF/DOCX/TXT 格式的已有简历或项目文档，AI自动识别并提取结构化信息，一键填入个人资料库；针对不同岗位可快速生成定制化简历，并导出为PDF。内置HR分享视角，生成分享链接供招聘方查看，附带AI问答辅助解读。

## 技术栈

- **前端框架**: Vue.js (纯前端 PWA)
- **数据存储**: IndexedDB (浏览器本地，无后端)
- **AI 能力**: DeepSeek API (文档提取 + 简历生成 + 岗位匹配 + 问答)
- **文件处理**: PDF/DOCX/TXT 解析
- **导出格式**: PDF

## 核心功能

### 文档智能提取
- 支持 PDF / DOCX / TXT 三种格式上传
- AI自动识别并提取：基本信息、工作经历、教育背景、项目经验、技能栈、证书
- 提取结果一键回填个人资料库
- 未归类补充信息自动存入知识库，供后续问答调用

### AI简历生成
- 从资料库选取内容，支持多版本管理
- 选择简历模板风格
- AI根据资料自动生成结构化简历初稿
- 手动微调后导出PDF

### 岗位匹配分析
- 粘贴目标岗位JD
- AI自动分析匹配度与差距
- 生成简历改进建议

### 求职问答咨询
- 基于知识库与个人资料进行AI问答
- 支持：面试准备、薪资咨询、Offer对比、职业规划等

## 快速开始

```bash
npm run dev

```
